📋 Architecture Overview

What is CJA?
A multimodal, agentic personal assistant built on a LangGraph state machine for intelligent journal management, automated task extraction, and daily summarization.
🎯 Key Features
  • Multimodal input (text, voice, images, PDFs)
  • AI-powered tagging & action extraction
  • Daily summary generation
  • Text-to-speech output (ElevenLabs)
  • Agentic tool execution (email, calendar)
  • Multiple storage backends
📊 Architecture Highlights
  • Event-driven state machine (LangGraph)
  • Microservices-inspired modularity
  • Multi-backend support (JSON/SQLite/Firestore)
  • Fault-tolerant with fallbacks
  • API-first design (FastAPI)
  • Cloud-native ready

🧩 Core Components Detail

1️⃣ Multimodal Ingestion
Purpose: Convert all input types to unified JournalEntry

Supported Inputs:
  • text_note - Plain text
  • voice_memo - Audio → STT
  • photo_ocr - Image → OCR
  • pdf_document - PDF extraction
  • code_snippet - Source code
  • email - Email parsing
  • calendar_event - Event data

Key Files: nodes/ingestion.py
2️⃣ LLM Processing
Purpose: Extract metadata and enrich entries

Extracts:
  • Contextual tags (Work, Personal, Task, etc.)
  • Action items (executable tasks)
  • Emotional tone (High Focus, Stressed, etc.)
  • Priority scores (1-10)
  • Key entities (people, places, dates)

Fallback: Rule-based processor (no API required)
Key Files: nodes/processing.py
3️⃣ Storage Management
Purpose: Persist data with pluggable backends

Backends:
  • JSON: Local files (./data/)
  • SQLite: Local database with indexes
  • Firestore: Cloud NoSQL database
  • Custom: Easy to extend

Pattern: Repository + Facade
Key Files: nodes/storage.py
4️⃣ Tool Execution Agent
Purpose: Execute actions via LangChain tools

Available Tools:
  • SendEmailTool - SMTP email
  • CalendarManagementTool - Calendar events
  • FileOperationsTool - File I/O
  • WebSearchTool - Web search

Agent: LangChain Agent Executor with ReAct
Key Files: nodes/agent.py, tools/external_tools.py
5️⃣ Reporting & Summarization
Purpose: Generate daily insights and summaries

Generates:
  • Daily theme (one-sentence summary)
  • Key decisions & learnings (3-5 bullets)
  • Journal narrative (2-3 paragraphs)
  • Pending actions (prioritized)
  • Suggested first task

Modes: LLM-powered or rule-based
Key Files: nodes/reporting.py
6️⃣ Text-to-Speech Output
Purpose: Convert reports to audio

Engines:
  • ElevenLabs: High-quality voice synthesis
  • pyttsx3: Local offline TTS

Features:
  • Natural speech formatting
  • Configurable voices
  • MP3 output

Key Files: nodes/output.py

🔄 LangGraph Workflow & State Machine

State Machine Architecture: LangGraph manages workflow as a directed graph with conditional routing based on user input.

Workflow State Transitions

START
↓
ROUTER (Conditional Entry Point)
Analyzes user input → Routes to appropriate path

Example: "Had a great meeting"

↓

↓

Example: "Send email to John"

📊 SUMMARY PATH

↓

↓

↓
END
Trigger: Summary keywords
Example: "Summarize my day"

State Transition Rules

From State Event/Condition To State Actions Performed
START user_input received ROUTER Parse and analyze input
ROUTER is_journal_input INGESTION Create JournalEntry
ROUTER is_action_command AGENT Initialize tool executor
ROUTER is_summary_request REPORTING Load all entries
INGESTION entry_created PROCESSING Extract metadata (LLM/Rules)
PROCESSING processed STORAGE Save to database
STORAGE saved END Return response
REPORTING report_generated TTS (if enabled) Convert to audio
TTS audio_created END Return report + audio

☁️ Deployment Architecture Options

🐳 Docker Deployment
Ideal For: Single server, simple scaling

Components:
  • Python 3.11 slim image
  • Volume mounts for data/audio
  • Environment variables via .env
  • Health checks enabled
Command:
docker run -d -p 8000:8000 \
  --env-file .env \
  -v ./data:/app/data \
  cja:latest
☸️ Kubernetes Deployment
Ideal For: Production, auto-scaling, HA

Resources:
  • Deployment (3 replicas)
  • Service (LoadBalancer)
  • ConfigMap + Secrets
  • PersistentVolumeClaim
  • Ingress (NGINX + TLS)
Scaling:
kubectl scale deployment cja \
  --replicas=5
🌩️ AWS ECS Fargate
Ideal For: Serverless containers on AWS

Architecture:
  • Route 53 (DNS)
  • CloudFront (CDN)
  • ALB (Load Balancer)
  • ECS Fargate (Containers)
  • RDS/Firestore (Database)
  • S3 (File storage)
  • Secrets Manager
Auto-scaling: Based on CPU/memory/requests
🔥 Google Cloud Run
Ideal For: Serverless, pay-per-use

Features:
  • Automatic HTTPS
  • Scale to zero
  • Native Firestore integration
  • Global CDN
  • Container-based
Command:
gcloud run deploy cja-service \
  --image gcr.io/PROJECT/cja \
  --platform managed
